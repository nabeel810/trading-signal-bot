# بوت إشارات التداول - دليل الإعداد من الموبايل

## الخطوة 1: إنشاء بوت تلكرام
1. افتح تطبيق تلكرام وابحث عن `@BotFather`
2. أرسل `/newbot` واتبع التعليمات لتسمية البوت
3. سيعطيك **Token** — احفظه جانباً (لا تشاركه مع أي شخص)
4. للحصول على **Chat ID**: أرسل أي رسالة لبوتك الجديد، ثم افتح هذا الرابط من متصفح الموبايل (بعد استبدال TOKEN):
   `https://api.telegram.org/botTOKEN/getUpdates`
   ستجد `"chat":{"id": ...}` في النتيجة — هذا هو Chat ID

## الخطوة 2: إنشاء حساب Twelve Data (بديل OANDA - يقبل التسجيل من أي مكان)
1. اذهب إلى موقع twelvedata.com عبر متصفح الموبايل
2. سجّل حساب مجاني بالبريد الإلكتروني فقط (لا حاجة لبطاقة بنكية ولا قيود جغرافية، لأنها بيانات فقط وليست وساطة)
3. من لوحة التحكم (Dashboard) ستجد **API Key** جاهزاً مباشرة بعد التسجيل
4. احفظ هذا المفتاح جانباً

## الخطوة 3: رفع الكود على GitHub
1. أنشئ حساب على github.com (مجاني)
2. أنشئ مستودع جديد (Repository) - اجعله **Private** (خاص)
3. من داخل المستودع: اضغط "Add file" → "Upload files"
4. ارفع الملفات الثلاثة: `signal_bot.py` و `requirements.txt` و مجلد `.github/workflows/signal-bot.yml`
   (عند الرفع، تأكد أن مسار ملف الـ yml يبقى بالضبط: `.github/workflows/signal-bot.yml`)

## الخطوة 4: إضافة المفاتيح السرية (Secrets)
من داخل المستودع على GitHub:
1. اذهب إلى **Settings** → **Secrets and variables** → **Actions**
2. اضغط **New repository secret** وأضف كل مفتاح على شكل اسم/قيمة:

| الاسم (Name) | القيمة (Value) |
|---|---|
| `TWELVEDATA_API_KEY` | مفتاح Twelve Data الذي حفظته |
| `TELEGRAM_BOT_TOKEN` | توكن بوت تلكرام |
| `TELEGRAM_CHAT_ID` | Chat ID الذي حصلت عليه |
| `PAIR` | `EUR/USD` (أو أي زوج آخر تريده، بنفس هذه الصيغة بالشرطة المائلة) |

## الخطوة 5: التشغيل
- بعد إضافة كل المفاتيح، البوت سيعمل تلقائياً كل 5 دقائق بدون أي تدخل منك
- للتجربة الفورية بدون الانتظار: من تبويب **Actions** في المستودع → اختر "Trading Signal Bot" → اضغط **Run workflow**
- لمتابعة سجل التشغيل والتأكد من عدم وجود أخطاء: تبويب **Actions** يعرض كل تشغيلة مع تفاصيلها

## ملاحظات مهمة
- البوت **يرسل إشارات فقط** — لا ينفذ أي صفقة تلقائياً، القرار والتنفيذ بيدك دائماً
- إذا لم تصلك أي إشارة لفترة، هذا طبيعي: الشروط (BOS + FVG/Order Block + ADX + الجلسة) لا تتحقق باستمرار، وهذا جزء من تصميم الاستراتيجية لتقليل الإشارات الخاطئة
- يمكنك تعديل `ADX_THRESHOLD` أو `RISK_REWARD_RATIO` أو `PAIR` مباشرة من ملف الكود أو من الـ Secrets
